# Customer Segmentation Using RFM Analysis

This project segments online retail customers according to their purchasing behaviour using **RFM analysis** and **K-Means clustering**.

## Project Overview

The analysis uses the Online Retail dataset to identify meaningful customer groups based on:

- **Recency** – the number of days since a customer's most recent purchase.
- **Frequency** – the number of unique invoices or purchases made by a customer.
- **Monetary** – the customer's total spending.

These segments can support targeted marketing, customer retention, and loyalty strategies.

## Files

- [`Customer_Segmentation.ipynb`](./Customer_Segmentation.ipynb) – Jupyter Notebook containing the complete analysis.
- [`Online Retail.xlsx`](./Online%20Retail.xlsx) – Online Retail transaction dataset.

## Dataset Summary

The original dataset contains **541,909 transactions** and the following fields:

- `InvoiceNo`
- `StockCode`
- `Description`
- `Quantity`
- `InvoiceDate`
- `UnitPrice`
- `CustomerID`
- `Country`

The notebook performs the following cleaning steps:

1. Removes 5,268 duplicate rows.
2. Excludes transactions without a `CustomerID`.
3. Removes cancelled invoices.
4. Removes transactions with a non-positive unit price.
5. Creates a `TotalPrice` feature using `Quantity × UnitPrice`.

After cleaning, the analysis uses **392,692 valid transactions** from **4,338 customers**. The transaction period runs from **December 1, 2010, to December 9, 2011**.

## Methodology

1. Load and inspect the Excel dataset.
2. Clean duplicate, missing, cancelled, and invalid records.
3. Calculate customer-level RFM metrics.
4. Standardize the RFM features with `StandardScaler`.
5. Use the elbow method to assess a suitable number of clusters.
6. Apply K-Means clustering with four clusters.
7. Profile and interpret the resulting customer segments.

## Cluster Profiles

The resulting clusters have the following average RFM values:

| Cluster | Approx. Customers | Recency (days) | Frequency | Monetary Value | Interpretation |
|---:|---:|---:|---:|---:|---|
| 0 | 3,054 | 43.70 | 3.68 | 1,353.63 | Regular or moderately engaged customers |
| 1 | 1,067 | 248.08 | 1.55 | 478.85 | Inactive or low-value customers |
| 2 | 13 | 7.38 | 82.54 | 127,187.96 | Highly valuable customers |
| 3 | 204 | 15.50 | 22.33 | 12,690.50 | Loyal and high-engagement customers |

Cluster labels are generated by K-Means and do not inherently represent a ranking. The interpretations above are based on the average RFM values of each cluster.
