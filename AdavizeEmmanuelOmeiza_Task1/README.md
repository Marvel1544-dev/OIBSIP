# Retail Sales EDA (Exploratory Data Analysis)

## Overview
This project contains an exploratory data analysis of retail sales data. The analysis is performed using Python and Jupyter Notebook to uncover patterns, trends, and insights in the retail sales dataset.

## 📁 Project Structure
```
AdavizeEmmanuelOmeiza_Task1/
├── EDA_Retail_Sales.ipynb          # Main Jupyter notebook with EDA analysis
├── retail_sales_dataset.csv        # Dataset file containing retail sales data
└── README.md                         # This file
```

## 📊 Dataset
- **File**: `retail_sales_dataset.csv`
- **Description**: Contains retail sales transaction data with various features related to sales, products, and customer information

## 📓 Analysis Notebook
- **File**: `EDA_Retail_Sales.ipynb`
- **Description**: Comprehensive Jupyter notebook performing exploratory data analysis including:
  - Data loading and inspection
  - Statistical summaries
  - Data visualization
  - Pattern identification
  - Trend analysis

## 🚀 Getting Started

### Prerequisites
- Python 3.7+
- Jupyter Notebook
- pandas
- matplotlib
- seaborn
- numpy

### Installation
1. Clone or download the project
2. Install required packages:
```bash
pip install jupyter pandas matplotlib seaborn numpy
```

### Usage
1. Navigate to the project directory
2. Launch Jupyter Notebook:
```bash
jupyter notebook
```
3. Open `EDA_Retail_Sales.ipynb`
4. Run the cells to see the analysis and visualizations

## 📈 Key Analysis Areas
- Sales performance metrics
- Data distribution analysis
- Trend visualization
- Statistical relationships
- Data quality assessment
